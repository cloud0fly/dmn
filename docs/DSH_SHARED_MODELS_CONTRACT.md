# P6-A：复用 DSH 已注册模型

本阶段仅现有双节点，不引入第三节点。通过 DSH 官方 llm 服务读取已注册 Provider/model 元数据，并由宿主执行该精确适配器；凭据与 Provider 设置留在 DSH，不复制 Desktop Profile、私有会话或工具权限到节点。

隔离 SDK 使用专用 LlmAdapter，经本机随机 capability IPC 请求宿主生成。节点仍持有独立固定根 Session 和私有命名空间。宿主逐次核对已运行轮次快照、节点、路由、Session、话题授权版本、单次输出限额和最后输入；拒绝工具、多模态及任何客户端 URL/凭据/文件路径。每轮 dispatch 在对应 Runtime Home 内用排他持久标记记录，重复相同请求仅可返回完整缓存，未知结果不得再次收费调用。Host/SDK 中断进入原有 unknown 对账流程。

目录发现仅证明模型已注册及能力可解析，不证明认证或生成成功；失败 Provider 单独报告，不回传原始错误、URL 或凭据。需要已知 >=32768 context 的文本模型。SDK 禁用重试、压缩、标题模型及工具；宿主只执行一次 prepared stream，不创建 Desktop agent。

选定 A/B 路由后显式应用为一个新的双节点群聊实例，保留旧数据库和 Runtime。新实例使用新的根 Session，模型/根/命名空间绑定不被原位覆盖；旧群聊可切回。节点系统提示词按对应 A/B 复制，私有记忆和旧历史仍留在原实例，不隐式跨模型传播。失败不切换当前实例，重试必须沿用请求标识。模型选择与实际讨论分别授权，应用模型不发起推理。

阶段顺序：先契约和故障测试，再 Host broker 与隔离 SDK，再新群聊配置与 UI，最后有界真实生成/恢复验收。不因列表存在而宣称全部 Provider 已验收。

思考能力按精确模型元数据传递，不按名称硬编码。保留 DSH 已设默认；元数据没有默认且不提供 off 时，使用其从低到高列表的首个等级作为共享 SDK 默认。允许 off 且没有默认时不干预。等级变化不扩大单次输出 Token、时间或总预算；思考 Token 同样计入输出限额。Provider 失败诊断只保留固定词表、HTTP 状态和官方允许的业务码，不回传原始错误、密钥、URL 或提示词。
